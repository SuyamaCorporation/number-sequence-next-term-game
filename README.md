# 数列 次の項 当てゲーム

数列の次の項を当てるゲームです。10種類の数列パターンをランダムに出題します。

## 機能

- 数列10種収録: 等差・等比・フィボナッチ型・三角数・平方数・素数・階乗・二項係数・2の累乗・2階等差数列
- 各問題で数列の最初の4〜6項を表示し次の項を入力
- ヒントボタン（カテゴリと公式を表示、使用時は得点半減: +5点 vs +10点）
- 正解後に公式と解説を表示
- スコアカウント（通し問題）

## 技術仕様

- 静的SPA（単一 index.html）
- Tailwind CSS CDN
- XSS対策: textContent で表示、parseInt で入力を数値に変換
- localStorage 不使用
